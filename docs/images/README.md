# Image Provenance

## Actual Application Captures

The current README gallery uses the following files:

| File | Source | Privacy processing |
| --- | --- | --- |
| `real-score-entry.png` | User-supplied Google Sheets screenshot | Visible student names covered with opaque blocks |
| `real-award-ranking.png` | User-supplied ranking screenshot | Visible student names covered with opaque blocks |
| `real-class-settings.png` | User-supplied class-settings screenshot | No names present; source metadata stripped |
| `real-output-settings.png` | User-supplied output-settings screenshot | No names present; source metadata stripped |
| `real-report-page-1.png` | First page of the user's actual generated PDF | Student name covered; rasterized without a searchable text layer |
| `real-report-page-2.png` | Second page of that PDF | Name inside the teacher comment covered; rasterized without a searchable text layer |

These are actual captures and PDF renderings, not recreated interfaces. Name masking is permanent in the published PNG pixels, rather than a removable PDF annotation, CSS overlay, or lightly blurred text. Screenshot dimensions and pixels outside the masking regions are preserved during processing. The original source images and PDF are not committed.

The project owner approved public display of these name-redacted captures, including the remaining assessment figures and comment text, for this portfolio.

Scores, class names, teacher-comment text other than the student's name, and the original settings remain visible as supplied. Name masking is not a guarantee of complete anonymization. Differences in reporting dates, titles, or column labels between captures are retained rather than retouched to imply a single synchronized session. These assets do not establish that live service acceptance tests were performed for the repository release.

## Legacy Mockups

These PNG files are reconstructed illustrations using fictional data, not screenshots of the actual academy program:

- `01-score-input.png`
- `02-generate-menu.png`
- `03-report-card-pdf.png`
- `04-award-ranking.png`

They are not captures of a live Google Sheets workbook, an actual generated PDF, or an actual ranking sheet. Previous README descriptions incorrectly presented them as anonymized screenshots and historical interface captures. That gallery and those descriptions have been removed.

The files remain only as legacy illustration assets, not as evidence of the deployed application's appearance or behavior.

Future captures must be reviewed for names, IDs, account details, private document links, and any other information not approved for public display before publication.

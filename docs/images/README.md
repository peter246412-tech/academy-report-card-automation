# Legacy Mockups

These PNG files are reconstructed illustrations using fictional data, not screenshots of the actual academy program:

- `01-score-input.png`
- `02-generate-menu.png`
- `03-report-card-pdf.png`
- `04-award-ranking.png`

They are not captures of a live Google Sheets workbook, an actual generated PDF, or an actual ranking sheet. Previous README descriptions incorrectly presented them as anonymized screenshots and historical interface captures. That gallery and those descriptions have been removed.

The files remain only as legacy illustration assets, not as evidence of the deployed application's appearance or behavior.

Any replacement showcase should use genuine captures from the application, with student names, IDs, scores, comments, account details, and private document links removed or replaced with approved synthetic data before publication.
